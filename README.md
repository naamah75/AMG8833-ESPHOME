# AMG8833 for current ESPHome

Fork of [TheRealWaldo/AMG8833-ESPHOME](https://github.com/TheRealWaldo/AMG8833-ESPHOME), migrated to ESPHome external components. Companion integration: [naamah75/thermal](https://github.com/naamah75/thermal), installable through HACS as a custom repository.

## Tested setup

ESPHome **2026.10.0**, Home Assistant **2026.10.2**, Wemos D1 Mini Pro (ESP8266, 16 MB flash) and Grove AMG8833. Verified by USB upload, live ESPHome API readings and a thermal camera image generated by Home Assistant. Other hardware and versions have not been verified.

## Wiring

| AMG8833 | D1 Mini Pro |
| --- | --- |
| SDA | D2 / GPIO4 |
| SCL | D1 / GPIO5 |
| GND | GND |

Supply your breakout board at its specified voltage. The tested Grove board responds at **0x69**; some boards use **0x68**. Check the I2C scan in the ESPHome logs.

## Install

1. Copy `secrets.yaml.example` to `secrets.yaml` and enter your Wi-Fi credentials.
2. Install ESPHome 2026.10.0 or newer. Newer versions are not automatically guaranteed compatible.
3. Run `esphome run amg8833.yaml` and select the USB serial port for the first flash.
4. Add the device using Home Assistant's ESPHome integration.

In ESPHome Device Builder, copy `amg8833.yaml` and `components/amg8833/` into its configuration directory. Merge the two secret keys into its existing `secrets.yaml`; do not replace other devices' secrets. After changing Wi-Fi, upload while the device is still reachable on its old network, or use USB.

This example enables API and OTA without authentication for initial testing. Set API encryption and an OTA password for your deployment; keep them in secrets.

## Thermal Vision camera

Install the [companion Thermal Vision fork](https://github.com/naamah75/thermal) and point its camera at the **Sensor Raw Pixels** entity. Copy the actual entity ID from Home Assistant:

```yaml
camera:
  - platform: thermal_vision
    name: Thermal Camera
    pixel_sensor: sensor.thermal_sensor_raw_pixels
    auto_range: true
    overlay: true

recorder:
  exclude:
    entities:
      - sensor.thermal_sensor_raw_pixels
      - sensor.thermal_sensor_pixels
```

`Sensor Raw Pixels` publishes 128 AMG8833 register bytes as Base64, preserving signed temperatures and 0.25 °C resolution. `Sensor Pixels` retains the original 64-byte format, clamped to 0..63.75 °C for compatibility with the original Thermal decoder. Do not select the raw entity with an unpatched upstream decoder.

The component reads the array once per interval, checks I2C errors and publishes minimum, maximum, average and thermistor temperatures. The binary sensor uses a 4 °C max/min contrast and a 5-second delayed off; it is a heuristic and does not reliably identify people.

## Migration

The removed `platform: custom` declarations are replaced by a local external component using ESPHome's I2C API. `esp8266:` and OTA platform configuration use current syntax. The old root header files remain historical references and are not compiled. The former min/max index sensors are not included in this example.

On Windows, if toolchain paths exceed the compiler's path limit, set `ESPHOME_ARDUINO8266_PREFIX` to a short writable directory before compiling.

No Wi-Fi passwords, compiled firmware with embedded credentials, device flash backups or Home Assistant tokens are distributed here.

# ESPHome AMG8833

Source code for creating firmware for an ESP8266 chip (d1 mini in my case) to use an AMG8833 sensor with [Thermal Vision](https://github.com/TheRealWaldo/thermal) via. [ESPHome](https://esphome.io).

Prefer to use [PlatformIO](https://platformio.org/)?  See [TheRealWaldo/esp8266-amg8833](https://github.com/TheRealWaldo/esp8266-amg8833).

## Building

This project uses [ESPHome](https://esphome.io).  You'll need to provide your own `secrets.yaml` in the root directory, providing `ssid`, `password`, and `domain` if you wish to use the [amg8833.yaml](amg8833.yaml) example configuration.

```bash
pip3 install esphome
esphome amg8833.yaml run
```

## Configuring

The [Thermal Vision](https://github.com/TheRealWaldo/thermal) camera can be configured by providing the [AMG8833CameraComponent](amg8833_camera.h)'s resulting sensor in HASS to the configuration option `pixel_sensor` instead of `host`.

### Example:
```yaml
  - platform: thermal_vision
    name: Prototype Thermal Camera
    overlay: true
    pixel_sensor: sensor.sensor_pixels
    auto_range: true
```

It's important to note that only the Camera sensor will work in this manner.  The other sensors are provided natively via. [ESPHome](https://esphome.io) and [amg8833.h](amg8833.h).

Also important to note; the pixel sensor is _very_, _very_ noisy!  You will probably want to exclude it from your HA history.

### Example:
```yaml
history:
  exclude:
    entities:
      - sensor.sensor_pixels
```
